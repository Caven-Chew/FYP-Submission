# FYP-Submission

Source code and offline evaluation materials for Chew Zhan Yi Caven's NTU Computer Science Final Year Project on measurement validity in LLM red-teaming.

## Contents

| Folder | Purpose |
|---|---|
| [pyrit-bench](pyrit-bench/README.md) | Final assessment application, portable judge contracts and regression tests. |
| [pyrit-bench-evaluation](pyrit-bench-evaluation/README.md) | Offline analyses, numerical inputs and reproduction instructions. |
| [practice-chatbots](practice-chatbots/README.md) | BrewBot and RoboBot controlled-study targets. |
| [pyrit-bench-sc3098](pyrit-bench-sc3098/README.md) | Classroom application and offline tests. |
| [pyrit-bench-workshop](pyrit-bench-workshop/README.md) | Workshop application, BrewBot and final slides. |

## Getting started

Open the README in the relevant folder and run its setup commands from that folder. Components use separate Python environments and configurations. The workshop app retains its original expiry after 7 September 2026; its offline checks are documented separately. Large workshop builds remain on the SharePoint link in its README.

Credentials, production databases, captured conversations, private respondent data and the separate human-rating corpus are excluded. See [data availability](pyrit-bench-evaluation/DATA_AVAILABILITY.md) for reproduction limits and each component's NOTICE for attribution. Existing upstream licences are retained; no new project-wide licence has been selected.
